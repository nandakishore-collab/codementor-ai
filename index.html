A small bug. A useful lesson.

def average(numbers):
    total = sum(numbers)
    return total / len(number)

scores = [70, 85, 90]
print(average(scores))
✦ Mentor explanation

Likely issue: the function receives numbers, but the return line uses number. Those names do not match. Use len(numbers) to count the items in the list.
